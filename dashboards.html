How to add a dashboard

Power BI: Publish → Share → Embed → copy the <iframe> code, replace a placeholder card with it.

Tableau Public: Publish → Share → Embed Code → copy the <script> + <div> snippet, drop it into a card.

Streamlit / Plotly: Deploy on Hugging Face Spaces or Render, then embed with an <iframe src="...">.
